Custom Shopify Online Store 2.0 theme for `f0chrv-j7.myshopify.com`.

## Local preview

```sh
shopify theme dev --store f0chrv-j7.myshopify.com
```

Shopify will open a browser login the first time. Use a store-owner or staff account with the Themes permission.

## Safe automatic deployment

The GitHub Actions workflow validates and pushes every commit on `main` to the exact theme stored in the `SHOPIFY_THEME_ID` repository secret. Add these repository secrets:

- `SHOPIFY_CLI_THEME_TOKEN`: password generated by Shopify's Theme Access app.
- `SHOPIFY_THEME_ID`: numeric ID of the unpublished or staging theme.

The workflow does not automatically publish the theme as live. This keeps the production storefront safe until the preview is approved.
